# Changelog

## 1.0

First version of VitaIRC for Nintendo 3DS (Old and New 3DS), with the IRC core of VitaIRC 1.5 for
PS Vita:

- Chat on the top screen; window tabs, text field, nick suggestions and an on-screen keyboard
  (slide to correct, accents on long press, symbols and emoticons) on the bottom screen.
- Panel with windows, users (operator actions) and menu; message actions with Y (quoted replies,
  mention, translate, copy, user card).
- User card with WHOIS and VitaIRC profile; my profile (name, bio, share), compatible with VitaIRC
  for PS Vita, Android and iPhone.
- Servers with SSL/TLS and SASL, presets, channel browser, translation (Google or ChatGPT), history
  on the SD card, IRCv3 chat history with bouncers, reconnection after closing the console.
