# Changelog

## 1.1

- **Image search** on Safebooru, Danbooru and Sankaku (with optional Sankaku account): thumbnail
  grid on the bottom screen, details and the picture on the top screen (zoom with L/R, move with the
  D-pad), **favorites** kept on the SD card, **save to the SD card** (`sdmc:/pictures/VitaIRC`) and
  **send to the chat** with the artist's name under it (Sankaku's expiring links are re-uploaded).
- Adult content is off by default and needs an 18+ confirmation in Settings; tags that sexualise
  minors are always filtered.
- Public favorites for your VitaIRC profile (SELECT in Favorites).
- Settings for the image upload service (Litterbox, ImgBB, Imgur, soju).
- Fixed: the app crashed when closing (the network was shut down while a connection was still
  closing) and the first CIA did not start.

## 1.0

First version of VitaIRC for Nintendo 3DS (Old and New 3DS), with the IRC core of VitaIRC 1.5 for
PS Vita:

- Chat on the top screen; window tabs, text field, nick suggestions and an on-screen keyboard
  (slide to correct, accents on long press, symbols and emoticons) on the bottom screen.
- Panel with windows, users (operator actions) and menu; message actions with Y (quoted replies,
  mention, translate, copy, user card).
- User card with WHOIS and VitaIRC profile; my profile (name, bio, share), compatible with VitaIRC
  for PS Vita, Android and iPhone.
- Servers with SSL/TLS and SASL, presets, channel browser, translation (Google or ChatGPT), history
  on the SD card, IRCv3 chat history with bouncers, reconnection after closing the console.
